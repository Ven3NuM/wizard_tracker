## JSX: HTML μέσα στη JavaScript, με λίγους κανόνες

Το JSX μοιάζει με HTML, αλλά το Vite το μετατρέπει σε κλήσεις JavaScript. Γι' αυτό έχει κάποιους
κανόνες που η HTML δεν έχει:

| Κανόνας | Παράδειγμα |
| --- | --- |
| Ένα στοιχείο στην κορυφή του `return` | τύλιξε τα πάντα σε `<main>` ή σε `<>…</>` (fragment) |
| Κάθε tag κλείνει | `<input />`, όχι `<input>` |
| `className` αντί για `class` | `<form className="setup">` |
| `htmlFor` αντί για `for` στο `<label>` | `<label htmlFor="dealer">` |
| Attributes σε camelCase | `onClick`, `maxLength`, `tabIndex` |
| Τιμές JavaScript σε `{ }` | `<p>{players.length} παίκτες</p>` |
| Σχόλια μέσα στο JSX | `{/* σχόλιο */}` |

Όταν ένα JSX πιάνει πολλές γραμμές, το βάζουμε σε παρενθέσεις μετά το `return`, για να μην «χαθεί»
στην επόμενη γραμμή:

```jsx
return (
  <main className="app">
    …
  </main>
)
```

## Χωρίζοντας την οθόνη σε components

Αν έγραφες όλη την εφαρμογή σε ένα `App`, θα είχες ένα αρχείο χιλίων γραμμών. Τη χωρίζουμε σε
κομμάτια με ένα καθαρό ρόλο το καθένα. Εδώ φτιάχνουμε το πρώτο: την οθόνη ρυθμίσεων, `Setup`.

```
App
└── Setup      (αριθμός παικτών, ονόματα, κανόνας hook, Έναρξη)
```

Ένα component χρησιμοποιείται σαν tag: `<Setup />`. Το «ζωγραφίζει» το component που το περιέχει,
εδώ το `App`.

## Modules: `export` και `import`

Κάθε component ζει στο δικό του αρχείο και **εξάγεται**:

```jsx
// Setup.jsx
export default function Setup() { … }
```

Όποιο αρχείο το χρειάζεται, το **εισάγει**:

```jsx
// App.jsx
import Setup from './Setup'
```

- `export default`: το «κύριο» πράγμα που εξάγει ένα αρχείο. Ένα ανά αρχείο. Το εισάγεις με όποιο όνομα θέλεις.
- `export` (χωρίς default): μπορείς να έχεις πολλά, και τα εισάγεις με το ακριβές όνομα σε αγκύλες:
  `import { useState } from 'react'`. Θα τα χρησιμοποιήσουμε από το επόμενο μάθημα.
- Το `'./Setup'` είναι σχετική διαδρομή από το τρέχον αρχείο. Το `.jsx` μπορεί να παραλειφθεί.

## Ο κώδικας αυτού του μαθήματος

Το `Setup.jsx` είναι προς το παρόν **στατικό**: σκέτο JSX, χωρίς καμία λογική. Τα κουμπιά δεν
αντιδρούν και τα ονόματα είναι πάντα τρία. Είναι σκόπιμο: πρώτα στήνουμε το πώς φαίνεται η οθόνη
και στα επόμενα μαθήματα της δίνουμε ζωή.

Πρόσεξε στον κώδικα:

- **`<fieldset>` και `<legend>`** ομαδοποιούν τα κουμπιά πλήθους με έναν τίτλο. Οι screen readers
  διαβάζουν «Αριθμός παικτών, 3».
- **`aria-pressed="true"`** λέει ότι το κουμπί «3» είναι πατημένο. Το CSS το χρησιμοποιεί για το
  πράσινο χρώμα, οπότε η εμφάνιση και η προσβασιμότητα βγαίνουν από το ίδιο attribute.
- **Το input μέσα στο `<label>`**: πατώντας το κείμενο «Παίκτης 1» εστιάζει το πεδίο, και ο screen
  reader ξέρει ποιο όνομα ζητάει το πεδίο.
- **`type="button"`**: μέσα σε `<form>`, ένα κουμπί χωρίς type είναι submit και κάνει reload τη
  σελίδα. Το κανονικό submit θα το δούμε στο μάθημα 5.

## Σύνοψη

- Το JSX είναι JavaScript: `className`, κλειστά tags, `{ }` για τιμές.
- Η οθόνη χωρίζεται σε components, ένα αρχείο το καθένα.
- `export default` / `import` συνδέουν τα αρχεία.
- Πρώτα στατικό UI, μετά λογική: έτσι θα χτίζουμε και τις υπόλοιπες οθόνες.
